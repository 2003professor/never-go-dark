# Traces

The simulator reads **processed** traces from `processed/<dataset>/*.csv` — one row per real
sample, in a unified schema (`t_s, bearer, dl_mbps, ul_mbps, rtt_ms, loss`), never interpolated
(zero-order hold). Every processed file maps 1:1 to one raw run.

The measured datasets are third-party and **not redistributed** here (licences — see
[`../../SOURCES.md`](../../SOURCES.md)). To build the processed traces yourself:

1. Download each dataset from its source (SOURCES.md) and unpack it under `raw/<dataset>/`.
   Each parser in `parsers/` prints the exact path and source URL it expects when a raw file
   is missing, so you can also just run step 2 and follow the messages.
2. From `simulator/`, run `make traces`. Each `parsers/parse_*.py` reads `raw/<its dataset>/`
   and writes `processed/<dataset>/` (plus a data card under `cards/`). Datasets whose raw
   files are absent are reported and skipped; the rest still process.

```
traces/
  parsers/      raw -> processed scripts, one per dataset (committed)
  raw/          <- place the downloaded datasets here (not bundled)
  processed/    <- generated by `make traces` (not bundled)
  cards/        <- generated data cards (not bundled)
```

Schema and the per-dataset column mapping are specified in [`../SPEC.md`](../SPEC.md) §3.3–3.8.
Full end-to-end steps are in [`../../REPRODUCE.md`](../../REPRODUCE.md).
